A tiny deterministic program that prints a single original, funny one-line pitch: a mute button for the voice in your head that replays your most embarrassing moments at 3 a.m. It takes no input, makes no network calls, and prints exactly the same line on every run.

## Run it

```sh
python3 main.py
```
